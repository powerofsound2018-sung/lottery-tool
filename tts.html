🔊 Gemini 語音生成工具

用 Google Gemini 的文字轉語音模型生成音色。API Key 只存在你的瀏覽器，直接呼叫 Google 的伺服器，不會經過任何第三方。

1 API Key

到 Google AI Studio 免費申請一組金鑰，貼在這裡。

⚠️ 這是純前端工具，生成時金鑰會直接從你的瀏覽器送到 Google，不會經過我們的伺服器。但因為是「明文放在前端」，別在公用電腦勾選記住，也別把這頁面分享給不信任的人。

2 選擇模型與音色

如果之後 Google 又推出更新版本，選「自訂模型代號」貼上正確 ID 就能用，不用等這個工具更新。（舊的 gemini-2.5 preview 模型現在限制只給先前用過的帳號使用，新帳號用會靜默失敗，建議直接用預設的 3.8 版。）

3.8 版支援額外指定語氣風格，留空就用預設自然語氣。

點 ▶ 可以聽一句示範（會用目前選的模型即時生成，消耗一點 API 額度），點了之後那個音色就會被選取，用來做上面第 3 步的生成。點 ☆ 可以收藏成最愛，之後就不用每次重新找。

3 輸入要念的文字

可以在文字前面加語氣指示，例如「用開心又興奮的語氣說：」，Gemini 會自動判斷語言（支援中文）。

常見問題
生成失敗、跳 CORS 或網路錯誤？
Google 的 Generative Language API 目前主要設計給伺服器端呼叫，少數瀏覽器/網路環境可能會擋掉直接從網頁發出的請求。如果一直失敗，把錯誤訊息貼給我，或改用有後端的環境呼叫同一支 API。

生成失敗，錯誤裡有 finishReason: OTHER，但沒有更明確的原因？
這通常代表模型有收到請求也扣了 token，但拒絕產生內容。常見原因是這組 API Key 的帳號／專案還沒有權限使用這個模型（例如舊版 gemini-2.5 preview 模型現在只開放給先前用過的帳號），或還沒開通計費。建議先改用預設的 gemini-3.8-flash-tts；如果還是失敗，去 Google AI Studio 用同一組帳號、同一個模型直接測試，確認是不是帳號本身的權限問題。

API Key 安全嗎？
金鑰只存在你瀏覽器的 localStorage（勾選「記住」時），生成時直接以你的瀏覽器身分呼叫 Google，沒有任何中繼伺服器會看到金鑰。建議在 Google AI Studio 幫這組金鑰設定用量上限。
