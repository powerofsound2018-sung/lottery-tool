🔊 Gemini 語音生成工具

用 Google Gemini 的文字轉語音模型生成音色。API Key 只存在你的瀏覽器，直接呼叫 Google 的伺服器，不會經過任何第三方。

1 API Key

到 Google AI Studio 免費申請一組金鑰，貼在這裡。

⚠️ 這是純前端工具，生成時金鑰會直接從你的瀏覽器送到 Google，不會經過我們的伺服器。但因為是「明文放在前端」，別在公用電腦勾選記住，也別把這頁面分享給不信任的人。

2 選擇模型與音色

如果 Google 之後推出更新版本（例如你說的 3.8 / 3 系列），選「自訂模型代號」貼上 AI Studio 顯示的正確模型 ID 就能用，不用等這個工具更新。

3 輸入要念的文字

可以在文字前面加語氣指示，例如「用開心又興奮的語氣說：」，Gemini 會自動判斷語言（支援中文）。

常見問題
生成失敗、跳 CORS 或網路錯誤？
Google 的 Generative Language API 目前主要設計給伺服器端呼叫，少數瀏覽器/網路環境可能會擋掉直接從網頁發出的請求。如果一直失敗，把錯誤訊息貼給我，或改用有後端的環境呼叫同一支 API。

API Key 安全嗎？
金鑰只存在你瀏覽器的 localStorage（勾選「記住」時），生成時直接以你的瀏覽器身分呼叫 Google，沒有任何中繼伺服器會看到金鑰。建議在 Google AI Studio 幫這組金鑰設定用量上限。
